# Task API

A lightweight REST API for managing tasks, built with Node.js and Express.

## Prerequisites

[Node.js](https://nodejs.org) v22.0.0 or higher

## Getting Started

1. Set up environment variables:
   Create a `.env` file in the root directory and configure your variables.
   ```env
   PORT=3000
   ```

2. Start the development server:
   ```bash
   npm run dev
   ```
   The server will watch for file changes and automatically restart.


## API Endpoints

 `GET`  Retrieve all tasks 
 `POST` Create a new task 
 `PATCH` Update an existing task 
 `DELETE` Delete a task
